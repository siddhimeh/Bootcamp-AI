## Machine Learning Assignments

### 07 - Student Performance Prediction using Decision Tree
File: `Decision_Tree.ipynb`

This assignment demonstrates the use of a Decision Tree Classifier to predict student performance.

Topics covered:
- Loading the Student Performance dataset using Pandas
- Creating a Pass/Fail target variable using the final grade (G3)
- Selecting features such as G1, G2, study time, failures, and age
- Splitting the dataset into training and testing data
- Training Decision Tree Classifiers
- Comparing different tree depths (`max_depth = 3, 4, 5`)
- Comparing training and testing accuracy
- Confusion Matrix and Classification Report
- Visualizing the Decision Tree
- Analyzing the effect of tree depth on model performance

Key Learning:
Increasing the depth of a Decision Tree increases its complexity and can improve training accuracy. However, a deeper tree does not always improve testing accuracy and may lead to overfitting.


### 08 - Linear Regression in Electronics Industry
File: `Linear_regression.ipynb`

This assignment demonstrates an application of Linear Regression in the electronics industry.

The model is used to study the relationship between the operating hours of an electronic device and its power consumption.

Topics covered:
- Creating an electronics-related dataset
- Selecting input and output variables
- Training a Linear Regression model
- Making predictions using the trained model
- Calculating Mean Squared Error (MSE)
- Calculating R² Score
- Visualizing actual data and the regression line
- Predicting power consumption for new operating hours

Application:
Linear Regression can be used in the electronics industry to estimate continuous values such as power consumption based on operating conditions.


### 09 - Unsupervised Learning using K-Means Clustering
File: `Unsupervise_learning.ipynb`

This assignment demonstrates the application of Unsupervised Machine Learning using K-Means Clustering.

A customer segmentation dataset containing Annual Income and Spending Score is used to identify groups of customers with similar characteristics.

Topics covered:
- Creating a customer dataset using Pandas
- Understanding unsupervised learning
- Selecting features for clustering
- Training a K-Means clustering model
- Creating three customer clusters
- Assigning cluster labels to observations
- Finding cluster centroids
- Visualizing customer clusters using Matplotlib
- Counting customers in each cluster
- Using the Elbow Method to analyze the number of clusters

Application:
K-Means clustering can be used for customer segmentation, where customers are grouped according to similarities in their characteristics without using predefined class labels.
